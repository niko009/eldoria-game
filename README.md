# Eldoria Game

Кроссплатформенная фэнтезийная онлайн-игра с постоянным миром, строительством королевств, автономными NPC, исследованиями, PvP и разрушаемым ландшафтом.

**Статус:** проектирование, рабочая концепция. Реализация ещё не начата.

## Документация

- [Дизайн игры и техническая архитектура v0.1](docs/ELDORIA_DESIGN_AND_ARCHITECTURE_v0.1.md) — согласованные механики, предварительные решения, риски, открытые вопросы и этапы разработки.

## Планируемая структура

- `client/` — Godot 4
- `server/` — ASP.NET Core
- `shared/` — сетевые контракты
- `tools/` — инструменты генерации мира
- `tests/` — тесты
- `infrastructure/` — окружение и развёртывание

Структура будет создаваться постепенно по мере реализации. Документация описывает намерения, а не уже готовые функции.
