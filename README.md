## TASK-018 — диагностика производительности (опубликована в v0.5.2)

Добавлена опциональная телеметрия FPS, p95 времени кадра, памяти, сетевой задержки и профиля графики: Godot → выделенный сервер → приватный .NET API → PostgreSQL. Без передачи идентификаторов устройств и переписки; лимит частоты, автоматическая очистка через 14 дней, закрытая аналитическая сводка. [Документация TASK-018](docs/TASK-018_PERFORMANCE_TELEMETRY.md). **Production v0.5.2: телеметрия протестирована через публичный WSS и PostgreSQL.**

## Release v0.5.0 — camp building and saved world

Пользователь разрешил выпуск v0.5.0 после TASK-014. Изменения TASK-011–014 включены в релиз: аналоговый джойстик на Android, выбор героя, прыжки, серверный сбор ресурсов, строительство костра/палатки и приватное сохранение мира через PostgreSQL 16 + .NET 10. Нет аккаунтов, логинов и паролей: устройство хранит случайный токен.

**Управление:** Windows WASD, Shift — бег, Space — прыжок, F — сбор, B — постройка (тип выбирается в UI); Android: левый джойстик, Sprint/Jump/Gather/Build, тип постройки выбирается сверху. Костёр — 3 wood + 2 stone, палатка — 5 wood + 2 herb.

Релизные проверки и известные ограничения — [TASK-014](docs/TASK-014_CAMP_BUILDING_RELEASE.md).

## Планируемая структура

- `client/` — Godot 4.5.2, GDScript (первый код уже есть)
- `server/` — выделенный ASP.NET Core сервер (план)
- `shared/` — сетевые контракты (план)
- `tools/` — инструменты мира (план)
- `tests/` — тесты (план)
- `infrastructure/` — Docker/PostgreSQL и деплой (план)

Рабочий процесс: отдельные ветки под задачи, тесты и фиксация результатов. Документация различает согласованные требования, план и реально проверенный функционал.
