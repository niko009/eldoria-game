# TASK-056 — первая итерация боевого визуала

**Основа:** `feature/TASK-055-targeting-camera-zoom`; **ветка:** `feature/TASK-056-combat-impact-vfx`; без релиза.

## Реализация

- После подтверждённого сервером удара по волку/оленю/кролику/манекену клиентам рассылается отдельное `combat_impact` RPC: короткие искры и всплывающее число фактически нанесённого урона. При попадании в препятствие луком — отдельная реакция. Отвергнутые атаки не должны создавать урон и VFX.
- Расход стрел, HP, бой, XP и инвентарь **не меняются**. Событие представляет только визуальное отображение решений сервера.
- `harvest_vfx.gd` ограничивает одновременно активные боевые эффекты шестью. HIGH: 10 искр за удар; LOW: 4. Эффекты исчезают менее чем за секунду; при disconnect все принудительно удаляются.
- Волк получил недорогие сглаженные low-poly части (10 сегментов сферы вместо кубов), диагональную анимацию лап и движение хвоста. Навигация, позиции и атаки остаются на сервере.
- Задача **не является полной художественной переработкой**: специализированную волчью GLB-модель, анимации укуса/смерти, звуки и эффекты магии выполнить далее по этапу 1.
