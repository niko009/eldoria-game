# TASK-074 — Самостоятельная прокачка магии (P0, TODO)

**Проблема:** боевые навыки `archery`, `spear`, `defense` есть в `combat_progression.gd` и Persistence API; отдельной `magic` специализации нет. Магические попадания не дают `magic XP`, поэтому рост персонажа плохо связан с игрой за мага.

**Модель:** `skills.magic` (XP и уровень от серверных подтверждённых магических действий) + понятный индикатор HUD. XP за успешное попадание (не за промах в стену), ограниченно за реальное лечение потерянных HP. Не начислять XP за самолечение при полном здоровье и бесконечное повторение по манекенам. Раздельно опыт героя и `magic XP` (не слепо копировать XP копья).

**Начальная прогрессия (баланс предварительный):** 1) старт огненный шар; 2) ледяная стрела после раннего уровня; 3) молния после следующего; дальше небольшие бонусы к урону/маноэффективности и синергии с staff. При миграции не отнимать доступ к уже известным заклинаниям у старых существующих игроков без явного механизма grandfathering; для нового мира можно использовать уровневые unlocks. Не допускать резкого разгона DPS.

**Отображение:** `Магия · уровень N · x/y XP`, иконки заклинаний, заблокированные навыки с причиной, бонус посоха, показатель маны/стоимость/откат. Одна выбранная цель = один подтверждённый hit/XP. Уровни и staff damage — серверные вычисления.

**AC:** после 10 подтверждённых попаданий XP магии растёт, XP копья/лука не меняется; сервер отклоняет поддельные XP/уровни; unlocks и затраты маны синхронны; сохранение/загрузка через PostgreSQL и legacy JSON после аддитивной миграции. Тест: Mage/Rogue/ Knight separation, spell targeting, reconnect/restart, level thresholds, infinite-farm prevention.
