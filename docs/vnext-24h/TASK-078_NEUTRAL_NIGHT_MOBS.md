# TASK-078 — Нейтральные, ответные и ночные звери (P1, TODO)

**Правило пользователя:** волки агрессивны постоянно; часть остальных животных не нападает первой, но отвечает после атаки; некоторые днём нейтральны, а ночью агрессивны. Не смешивать «настороженность» с принудительной агрессией.

**Предлагаемые мобы и поведение:**
1. **Бык (`bull`)** — нейтральный, пасётся; при ударе атакует обидчика (радиус агрессии ограничен); спадает агрессия после 10–15 с без боя. 90–110 HP. Модель: Quaternius Ultimate Animated Animal Pack.
2. **Лиса (`fox`)** — пугливый нейтральный зверь, обычно убегает, иногда защищается, не становится рейдовым врагом. 28–35 HP; быстрые повороты, ценная шкура. Модель: Quaternius Ultimate Animated Animal Pack.
3. **Бродячая собака (`stray_dog`, модель Husky/Shiba)** — днём нейтральная; **ночью** патрулирует и может нападать первой, только в пределах зоны; возвращается к нейтральному состоянию утром. 45–65 HP. Альтернатива вместо собаки: отдельная стилизованная ночная тварь из CC0 монстр-пака, если животный вид кажется неподходящим.
4. **Олень** — не должен преследовать игрока, остаётся добычей и убегает по TASK-077.

**Сервер:** конечный автомат `idle/graze/alert/retaliate/chase/attack/return_home/dead`, события урона как trigger, target id/агро, радиус, time-of-day серверного цикла, откат атаки, смерть/лут/respawn, синхронизация фаз. Не доверять времени телефона; один мир — одинаковые состояния на Android/Windows.

**Количество:** +3 новых вида, 2–4 экземпляра каждого; лимит общего количества активно тикающих врагов и бюджет анимаций для слабого Android. Не создавать внезапно сотню мобов. Добыча и XP различаются по опасности; нельзя бить с полной безопасностью через стену.

**AC:** игрок проходит рядом с быком днём — нет атаки; бьёт — получает ответный удар; собака днём игнорирует, ночью атакует, после рассвета прекращает преследование; лиса сохраняет базовое поведение; все 3 модельки с анимациями, loot+XP, тесты 2 клиентов/рестарт/переход день↔ночь. Зависит от TASK-079.
