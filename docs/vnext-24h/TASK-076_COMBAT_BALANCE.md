# TASK-076 — Сделать бой медленнее и честнее (P0, TODO)

**Наблюдение пользователя:** волки группой очень быстро убивают мага; игрок часто убивает мобов за 1–2 удара или сам гибнет очень быстро. Нужны читаемые атаки, время на реакцию, расходники и тактика.

**Предварительная цель баланса (требует реального плейтеста):** обычный волк — бой соло 8–15 секунд, олени/нейтральные — 5–12 секунд при нормальном попадании; элитный волк 25–45 сек для двоих. Урон игроку от одного волка снизить примерно до 6–8 за укус вместо 12; от альфы примерно до 10–12 вместо 18, затем настроить по тестам. Встреча с 3 волками не должна давать синхронный тройной укус в один кадр: волки атакуют поочерёдно, 1–2 одновременных нападающих, остальные кружат/занимают позицию. Нужны предупреждающая анимация, интервалы и краткое окно на уклонение. Не увеличивать HP всех мобов механически в 3 раза без оценки DPS магии/копья.

**Команда:** рыцарь со щитом отвлекает, маг держит дистанцию, разбойник может уклоняться/добивать. `Shield` и одноручный staff/sword — отдельные слоты (TASK-072). Волков распределять по целям, не заставлять всех бежать за магом. Урон магии должен зависеть от skill/staff, но не возрастать быстрее прогрессии HP.

**AC:** таблица эталонных damage/TTK от 1–3 волков для 3 классов, без неустранимых блокировок от стана, серверная проверка атак; визуально понятно, когда удар наносится; есть реальное время применить повязку/манапот/блок. Безопасность: не делать врагов беспомощными. Выполнить плейтест двоих на Android/Windows минимум 3 серии боёв.
