# TASK-080 — Исправить зум камеры на реальном Android (P0, TODO)

**Проблема пользователя:** увеличение/уменьшение камеры на Android не работает, несмотря на зелёный синтетический тест. Расхождение между симуляцией жестов и реальным устройством — подтверждённое практикой, а причина пока **не установлена**.

**Что уже есть:** `client/platform_input.gd` обрабатывает pinch только при двух касаниях **в верхней правой части** (X > 50% ширины, Y < 72% высоты), скрытому HUD-кластеру может не хватить области; `CAMERA_MIN_DISTANCE=4.8`, `CAMERA_MAX_DISTANCE=19.0`, `CAMERA_DEFAULT_DISTANCE=13`. Система выбора цели (`main.gd`) также слушает тапы; возможен конфликт ввода.

**Диагностика:** добавить диагностический overlay/логирование (только для debug сборки): количество пальцев, координаты, события `_input/_unhandled_input`, текущая дистанция, перехват GUI. На 2 физических Android проверить pinch на пустом участке и при соседстве joystick/HUD, camera lock и выбор цели. Отличить жесты от тапа по времени/смещению.

**Исправление:** позволить два пальца в любой **не UI** области мира (а не только в неудобном узком углу); второй палец должен отменять действие «выбрать моба» для данного жеста; не конфликтовать с движением и скроллом инвентаря. Добавить надёжный fallback `+` / `−` (компактный, скрываемый в настройках) для тех телефонов, где pinch всё равно неудобен.

**AC:** pinch действительно меняет `camera_distance` и визуальный масштаб модели на двух физических Android (разрешения/плотности разные); +/- тоже работают; zoom не вращает камеру и не нажимает «УДАР»; ограничения не дают залетать внутрь героя/сквозь лес. Headless `task055_targeting_zoom_e2e` дополнен integration проверками и Android screenshot/логами.
