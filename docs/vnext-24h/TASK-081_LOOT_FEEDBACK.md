**Дизайн:** в момент серверного подтверждения добычи справа/сверху от HUD показывать карточки «+2 мясо», «+1 шкура», «+1 кость», «+XP магии 2» с маленькими иконками, упорядоченной очередью и анимацией (не блокирующей UI). Для редкого зверя — заметный более долгий тост. В мире на 1–2 секунды короткий всплывающий маркер у туши, с ограничением числа активных эффектов на Android. Журнал последних 5 событий добычи/урона при желании, без истории в БД.

Для идентичного RPC сделать event id/idempotency при необходимости, чтобы не дублировать анимации.

**AC:** при убийстве оленя сразу видны `+2 мясо +1 шкура +1 кость`, после общей охоты каждый рядом видит свою награду, маг видит отдельно магический XP; без дублирования при sync/reconnect; не перекрывает здоровье/ману/выбор цели.
