## Проверка перед добавлением

1. Скачать ассеты с **официального** сайта автора, зафиксировать файл/дату/страницу лицензии CC0 в `client/assets/licenses/` (текст лицензии или URL, без копирования лицензированных платных моделей).
2. Проверить glTF импорт Godot 4.5.2, наличие Skeleton3D, AnimationPlayer/AnimationTree и отдельных Attack/Death/Walk/Run/Idle; не считать наличие перечисленных анимаций для каждой конкретной модели подтверждённым до импорта.
3. Проверить пропорции к человеку, UV/materials, прозрачность, scale, коллизии; риг-анимации не перепутывать между быком/лисой/хаски.

5. Реальные животные выглядят **low-poly**, не фотореалистично. Не скачивать случайные модели CC-BY без проверки атрибуции; Poly Pizza может требовать иной лицензии для отдельных файлов, основной источник безопаснее.
