## Изменения v0.5.11 относительно v0.5.10

- Защита лагеря от нескольких волков, HP лагеря, ремонт и поражение; базовая тактика стаи.
- Расширенный крафт (повязки, ремонтные комплекты, копьё, лук, щит, стрелы), подсветка доступных рецептов, сортировка и счётчик мастерской.
- Прицельный лук: проверяемые сервером попадания, промахи, расход стрел, блокировка деревьями/камнями/рельефом.
- Два кролика, два оленя (мирные NPC), два тренировочных манекена, обновлённые простые модели и анимации.
- Постоянные навыки `archery`, `spear`, `defense`: сервер начисляет XP за валидные действия, уровень отображается в HUD. **Уровни пока не меняют урон/защиту.**
- Поддержка постоянного инвентаря и навыков в PostgreSQL, без смены анонимной идентификации.

## Ограничения

Физические Android-устройства, реальные FPS/нагрев и длительная игровая сессия на v0.5.11 ещё **не проверены**. Android APK использует debug-подпись, Windows ZIP без publisher code signing. При восстановлении после сбоя **не накатывать старый дамп PostgreSQL поверх новых достижений автоматически**. Исторические отчёты v0.5.10 остаются валидны только для предыдущей версии.
