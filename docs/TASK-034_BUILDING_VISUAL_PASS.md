# TASK-034 — Camp Structures & Build Feedback Visual Pass

**Дата:** 3 ноября 2026. **База:** `feature/TASK-033-character-equipment`. **Ветка:** `feature/TASK-034-buildings-vfx`. **Без релиза и деплоя:** production продолжает работать на v0.5.7.

## Цель и результат
Закрепить визуальный стиль первого лагеря в Eldoria. Улучшения видны в существующем `Main.tscn` и настоящем игровом мире, не в отдельном концепт-арте.

- **Костёр:** зольное кольцо, угли, подвесной походный котелок с крышкой и опорой, две тлеющие точки. Существующее пламя Godot ShaderMaterial и старые камни/дрова сохранены. **Никаких постоянных новых источников света**.
- **Палатка:** контрастные тканевые полосы по скатам крыши, вышивка и акцент входа, лежанка, подушка, небольшой деревянный сундук. Тканевые полосы и вышивка объединены в один `SurfaceTool` mesh, без дорогих прозрачных материалов или текстур.
- **Сбор:** вместо одинаковых круглых частиц для всего — деревянные щепки, осколки камня и листья (три лёгкие общие `Mesh`).
- **Строительство:** кратковременное золотистое кольцо + пыль после подтверждённого размещения. Не запускается при движении preview и восстановлении сохранённого мира. Одновременно максимум **4** эффекта, удаление через 1,2 с. Старая озвучка размещения сохранена.

## Android Low / High и сохранение геймплея

- **Android Low:** дополнительные мелкие предметы интерьера, котелок и тлеющие точки **скрываются**. Заметные базовые материалы, зольное кольцо и полосы крыши остаются; активное количество draw calls меньше.
- **High:** видны все предметы декора. Переключение качества теперь проходит и по уже созданным постройкам/превью, не только по лесу.
- Не менялись `BUILDING_SCRIPT.COSTS`, `RADII`, положения объектов, идентификаторы ресурсов, состояние PostgreSQL, коллизии, WSS, RPC, количество игровых ресурсов и логика списания.
- На headless dedicated сервере `building_object.gd` не создаёт 3D mesh, `harvest_vfx.gd` не создаёт пыль/вспышки.
- **Не заявляем рост Android FPS:** это визуальная задача, физический мобильный performance-test ещё необходим. Декор High увеличивает число mesh-объектов на постройку и требует проверки в насыщенном постройками мире.
