## Игровые изменения v0.5.11 → v0.5.12

1. TASK-050: навыки `archery`, `spear`, `defense` дают реальные серверные боевые бонусы до 5 уровня; панель «Навыки» показывает XP и эффекты. Сохранение XP использует прежнюю схему PostgreSQL.
2. TASK-051: защитник со щитом отвлекает ближайших волков на 5 секунд, радиус 10 м, откат 15 с. Над ним появляется маркер «ЗАЩИТНИК», видимый другим игрокам.
3. TASK-052: **три игровых класса** — Рыцарь (минус 10% входящего урона и эксклюзивный «Зов» со щитом), Разбойник (+10% скорость, рывок 2,5 м и откат 9 с), Маг (100 маны, регенерация 8 ед/с, лечение раненого игрока на 35 HP за 40 маны с откатом 12 с).
4. Вне подключения класс выбирается свободно; внутри игры менять класс разрешает сервер только живому игроку рядом с костром. Навыки оружия и предметы остаются доступными всем классам.
5. `Q` на Windows и пятая кнопка способности на Android. Для мага есть индикатор текущей маны; для классов разные названия действий.

## Проверки и инцидент запуска

- `bash tests/run_dev_gameplay_e2e.sh` — полный повторный запуск **PASS**. Первоначальный прогон выявил нестабильный тест Android touch; отдельные три повтора и повторный полный набор прошли.
- `tests/run_task050_skills_network_e2e.sh`, `tests/run_task051_shield_network_e2e.sh`, `tests/run_task052_classes_network_e2e.sh` — **PASS** с dedicated WebSocket и двумя независимыми Godot-клиентами.
- Реальный экспорт `--build-only` — `BUILD_ONLY_PASS`, `SHA_MATCH`, `CERT_MATCH`. Продакшн-публикация `--deploy` — `ELDORIA_RELEASE_SUCCESS 0.5.12`.
- **Временная проблема после переключения:** Godot дважды не смог загрузить мир из Persistence API из-за таймаута (17:27:00 и 17:27:11 UTC), вследствие чего первый внешний WSS-тест получил HTTP 502. Systemd перезапустил Godot; в 17:27:17 UTC загрузились **5 профилей и 120 истощённых ресурсов**, сокет TCP 7788 активен.
- Повторный внешний тест **PASS**: два независимых клиента через `wss://bacus.dev/eldoria/ws`, Mage + Rogue, правильные способности на UI, шесть NPC, движение обоих игроков.
- После восстановления: оба systemd-сервиса `active`, `ss` показывает Godot на порту 7788, в проверенных логах с 17:27:18 UTC **0 ошибок**. Предыдущие данные мира сохранились.

## Ограничения и следующая работа

- **Реальные Android-устройства и производительность FPS версии 0.5.12 ещё не проверялись.** Нужно протестировать два Android и Windows в одной игровой сессии, включая рывок, лечение и ночную волну.
- Стоит исследовать таймауты Persistence API при первом старте новой версии и улучшить startup readiness/retry, чтобы не получать 502 при следующем переключении.
- Маг пока лечит наиболее раненого **живого игрока** в радиусе 6 м независимо от дипломатии; фильтр союзников появится с фракциями.
- Пока нет дерева классовых талантов, полноценной анимации заклинаний или механики PvP-команд.
