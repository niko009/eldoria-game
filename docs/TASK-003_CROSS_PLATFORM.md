# TASK-003 — общий Godot-клиент для Windows и Android (2026-11-01)

**Статус:** бинарные сборки созданы, автоматические Godot E2E пройдены. **Проверка Windows и Android на физических устройствах остаётся обязательной.**

## Одна кодовая база
- Единственный игровой проект: `client/project.godot`, единственная сцена `client/Main.tscn`.
- Общие мир, персонажи, механики движения и сетевой протокол: `client/main.gd`.
- Платформенный ввод изолирован в `client/platform_input.gd`: PC WASD + перетаскивание ПКМ для камеры; Android экранные стрелки, свайп справа для вращения, экранная кнопка Wave.
- Оконный режим, F11, размеры 1280×720/1600×900/1920×1080: `client/display_settings.gd`. На Android экраном управляет ОС.
- Клиентские профили качества в `client/graphics_profile.gd`: Android Low (уменьшена детализация листвы, тени выключены) / High; Windows High по умолчанию. Объекты остаются на тех же местах.
- Сетевое действие Wave: отправка на сервер, проверка ID отправителя, broadcast всем клиентам. Пока это тестовое взаимодействие, не боевая система.

## Общий сервер
**Текущая рабочая реализация:** выделенный headless **Godot ENet** сервер, использующий ту же сцену:
```bash
godot --headless --path client -- --dedicated-server
```
UDP 7777; сервер не создаёт себе аватар. Windows и Android используют один и тот же ENet-клиент и должны вводить одинаковый IPv4 сервера. Если сервер в LAN, открыть UDP 7777 в брандмауэре и убедиться в доступности из обоих устройств. `127.0.0.1` на телефоне означает **сам телефон**, а не PC.

Сервер **не является** запланированным авторитетным ASP.NET Core/.NET сервисом. .NET транспорт и сериализацию нужно согласовать и перепроверить до миграции. Не считать текущую проверку скорости перемещения защитой от читов. Публичный интернет-доступ не настроен и не подтверждён; обычный Cloudflare Tunnel для HTTP не проксирует произвольный ENet UDP.

## Правила проверки на устройствах
1. Распаковать ZIP целиком, запустить Eldoria.exe; проверить мышь, WASD, F11, выбор разрешения.
2. На Android установить APK v0.1.1, проверить масштаб UI и экранные кнопки, переключение Low/High, движение камерой.
3. Запустить сервер в LAN; на обоих клиентах указать IPv4 хоста; проверить двух игроков, Wave, отключение/повторный вход и смену устройств. Записать системные логи/скриншоты, FPS и сетевые ошибки. **Пока этого не сделано, MVP-0 на реальных Windows + Android не принят.**
