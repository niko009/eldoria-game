# TASK-032 — Mobile HUD Visual Lock (разработка, без релиза)

**Дата:** 3 ноября 2026. **База:** `release/eldoria-v0.5.7`. **Ветка:** `feature/TASK-032-mobile-hud-lock`.
**Статус:** визуальная итерация, **НЕ опубликована**. Production остаётся v0.5.7.

## Проблемы реального Android-скриншота

- Системные иконки Android перекрывали верхние игровые кнопки.
- Нижние пять прямоугольных кнопок правой стороны занимали много вертикального пространства и закрывали вид леса.
- Статус «ELDORIA ONLINE · ... Please update ...» смешивал техническую диагностику с игровым HUD и был мелким.
- Снизу hotbar находился слишком близко к системной полоске жестов.
- На широком телефоне приложение показывало **чёрные боковые полосы**, потому что игра 1280×720 рисовалась с сохранением 16:9. Скриншот 1280×576 демонстрировал 1024×576 игрового изображения + 128 px чёрных полей по обе стороны.

**Важно:** исходный screenshot пользователя содержит сообщение `Please update Eldoria client to v0.5.7` — это отдельно указывает на **устаревшую клиентскую сборку**, а не обязательно на дефект HP или ресурсов.

## Исправленная композиция

1. **Сверху слева:** компактная «карточка персонажа» с акцентом аватара, именем, реальной полосой HP и минимальным индикатором соединения вместо служебного текста. При ошибке версии или подключения — отдельный читаемый warning под ресурсами (не прятать ошибку).
2. **Ресурсы:** три самостоятельных полупрозрачных чипа wood/stone/herb, векторные иконки и реальные численные значения; никаких материалов или количеств в hotbar.
3. **Сверху справа:** четыре круглоскруглённых иконки «рюкзак», «строить», «крафт» и «настройки» с tooltip и прежними сигналами.
4. **Справа:** вместо столбца пять прямоугольников — компактная группа **четырёх** круглых действий: удар (основное), сбор, прыжок, бег. Дублирующий рюкзак удалён справа, доступен в верхнем меню. Пятой функции геймплея не потеряно.
5. **Снизу:** hotbar на 6 инструментальных слотов, без количества; топор по-прежнему слот 4, состояние server-authoritative; небольшая подсказка об экипированном топоре.
6. **Безопасные зоны:** минимум 49 виртуальных пикселей сверху в mobile/test-mobile, минимум 30 снизу; реальные `DisplayServer.get_display_safe_area()` значения могут увеличить отступы. Плюс отступы слева/справа.
7. **Широкий экран:** `display/window/stretch/aspect="expand"` для устранения чёрных боковых полос; базовая виртуальная область `1024×576` вместо `1280×720`, чтобы UI не был чрезмерно мелким. 3D мир не обрезается и серверные координаты не меняются.
8. **Окна меню:** более согласованные палитра/рамки, безопасное размещение относительно top/bottom. Исправленный TASK-030 `EldoriaTouchScroller` сохраняется неизменным.

## Графический стиль

Stylized fantasy: тёмный зелёно-серый полупрозрачный HUD, тёплый приглушённый золотой акцент, минимальное количество границ и текста, векторные иконки вместо зависящих от emoji-шрифтов символов. Никаких эффектов SSAO, дорогих shader-ов или новых draw-call-heavy 3D-объектов.

- `client/tests/live_ui_smoke.gd`: прежний inventory/equip/health UI.
- `client/ui_preview/preview_smoke.gd`: UI preview.
- `client/tests/android_modal_scroll_e2e.gd`: исправленная ранее прокрутка свайпом и обычные тапы на Android.
- `tests/run_dev_gameplay_e2e.sh`: **PASS, exit 0**, полный повторный прогон: ENet + dedicated, WSS с двумя игроками, PostgreSQL/сохранение, крафт, PvE, ресурсы, Android joystick, исправление TASK-030 touch scrolling и OpenGL.
- Godot 4.5.2 import, `live_ui_smoke.gd`, `preview_smoke.gd`, `task032_hud_e2e.gd`: **PASS**.

## Scope и следующий этап

**Не менялись** PostgreSQL, серверные RPC, auth, атаки, крафт, persistence и release manifest. **Релиз/деплой APK/Windows не делать до решения пользователя.**

После просмотра этих скриншотов пользователь должен оценить UI по реальной компоновке. Следующий visual pass — **персонаж, оружие в руках и 3D-модели построек** с тем же художественным языком. К механикам голода/ночных волн возвращаться после согласования визуального стандарта.
