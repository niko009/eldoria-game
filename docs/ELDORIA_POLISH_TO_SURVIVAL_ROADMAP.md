## Принцип

Выпускаем **играбельные, проверенные вертикальные срезы**, а не добавляем десятки сырых систем. Существующие классы, XP, 7 рецептов, личный инвентарь, волны и PostgreSQL **не переписывать**. Переиспользовать сохранения, серверную валидацию и действующие сетевые тесты.

### Правила готовности каждого этапа

- Godot headless-import + профильные проверки + dedicated WSS с двумя реальными клиентами + регрессия старого кода.
- Для визуальных этапов — настоящий OpenGL-render (не только headless); отдельно проверить Android Low/High.
- Для релиза — Android APK и Windows ZIP из одной версии, backup перед деплоем, сверка SHA-256 публичных файлов, публичный WSS smoke. **Никаких автоматических релизов без просьбы пользователя.**
- Изменения БД требуют миграции, независимого PostgreSQL-теста и backup/rollback.

## Основные технические риски

1. Последний измеренный Android Low baseline (v0.5.8) около **22,8 FPS avg**; новые эффекты **нельзя** называть оптимизированными на телефоне без свежих измерений.
2. Некоторые виды животных уже получили GLB, но волк ранее оставался геометрической заглушкой; внешнее художественное качество нельзя подтвердить только unit-тестами.
3. Масштабная разрушаемость грунта, полноценные NPC и PvP — отложенные высокорисковые системы. Не смешивать с фазой полировки.
