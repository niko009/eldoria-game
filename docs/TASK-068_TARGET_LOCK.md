# TASK-068 — Выбор противника и атака по цели

- Android: коснуться моба или нажать кнопку «ЦЕЛЬ» (циклический выбор видимых мобов); кнопка «УДАР» / «МАГИЯ» атакует выбранного.
- Windows: правый щелчок по мобу или Tab для выбора видимых целей; левая кнопка / J — атаковать. Второй клик по выделенной цели снимает выделение; правый щелчок по пустому месту также снимает.
- Над выделенным противником отображаются кольцо, название и HP; при смерти или уходе далее 35 м выделение снимается.
- Сетевой протокол: только числовой target_id, не доверять клиентским координатам или HP. Старый вызов без target_id = свободное наведение.
- Ближний бой проверяет серверные HP, дистанцию (3 м / копьё 4.5 м), разницу высот и препятствия. Лук и магия автоматически наводятся на серверный центр выбранной цели, проверяют дальность 12 м и препятствия; ни соседние мобы, ни недопустимый ID не могут случайно заменить выбранного.
- Сохранили расход стрел, маны, перезарядку, XP и существующую механику без выбранной цели.
- Тест: `client/tests/task068_target_lock_e2e.gd`, проверяет selection UI, ближний бой, стаю, лук, мага, расход, invalid target, дистанцию, сброс после смерти и ввод с экрана.
