# Eldoria v0.5.8 — production release (TASK-032–035)

**Дата:** 3 ноября 2026 г. **Статус:** RELEASED, проверен на production.  
**Точный source SHA, из которого собран APK/Windows/dedicated:** `d1cb0dd01836ab1838b137c38a15cd0f550bcc0e`.  
**Ветка:** `release/eldoria-v0.5.8`.  
**Процедура:** `sudo eldoria-release 0.5.8 release/eldoria-v0.5.8 --deploy`.

## Состав

- TASK-032: обновлённый полноэкранный мобильный HUD, ресурсы сверху, инструменты снизу, safe-area Android, группа четырёх боевых кнопок, окна.
- TASK-033: оригинальная 3D-модель каменного топора в анимированной руке всех трёх KayKit героев; серверное подтверждение экипировки, синхронизация для других игроков и поздних подключений.
- TASK-034: новая детализация костра и палатки, короткий эффект завершённого строительства, разная геометрия частиц древесины, камней и растений. Декор скрывается в Android Low.
- TASK-035: персонаж поворачивается к реальному ресурсному объекту после подтверждения сервера; без топора не делает неуместный рубящий удар; кратковременные 3D маркеры WOOD/STONE/HERBS с лимитом 5.
- Сохранены все прежние геймплейные механики v0.5.7: совместный WSS-мир, сбор, крафт, постройки, волк/HP, сохранение и простая анонимная идентификация.

**В release нет SQL-миграций и новой .NET Persistence API.** Godot dedicated обновлён синхронно с клиентами, так как TASK-033 добавил визуальный RPC.
