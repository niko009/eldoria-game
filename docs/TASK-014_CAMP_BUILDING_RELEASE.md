# TASK-014 — первый лагерь Eldoria и релиз v0.5.0

Дата: 2 ноября 2026. Разрешение на релиз дано пользователем.

## Новые игровые механики
- Строительство **костра** (3 дерева, 2 камня) и **палатки** (5 дерева, 2 растения).
- Windows: выбор постройки в UI, клавиша **B**. Android: выбор в UI + кнопка **Build**. Оба типа построек имеют стилизованные 3D-модели, созданные непосредственно в Godot без сторонних ассетов.
- Сервер выполняет проверку ресурсов, расстояния 2.1–6.5 м, координат на земле, уклона, пересечений с препятствиями и существующими постройками, лимита 300 построек.
- Ресурсы списываются **только после успешного сохранения**: при ошибке записи в PostgreSQL инвентарь и объект возвращаются в исходное состояние.
- Все игроки получают новые постройки через надежные RPC, новый подключившийся игрок получает полный снимок построек.

## Архитектура и хранение
- Godot dedicated server → приватный .NET 10 API → отдельная PostgreSQL 16.
- Четыре таблицы: `eldoria_worlds`, `eldoria_players`, `eldoria_resources`, `eldoria_buildings`. Запись построек, инвентаря и ресурсов в **одной PostgreSQL-транзакции**. Чтение согласованного снимка, optimistic concurrency `revision`.
- Без регистрации: случайный секрет устройства, сервер хранит только SHA-256 токена. Удаление данных приложения приводит к утрате идентификатора. Нет восстановления аккаунта.
- API привязан к `127.0.0.1:19091`, PostgreSQL к `127.0.0.1:5439`, внешний доступ возможен только через игровой WebSocket WSS Cloudflare/Caddy.
- Для production секреты читаются сервисами из локальных файлов с ограниченными правами; секреты не хранятся в Git.

## Важно
- Игровой мир пока небольшой, рассчитан на 10 игроков. Нет удаления построек, приватной земли, боевых механик, обмена предметами, полноценной системы ролей и масштабируемой серверной экономики.
- Сохранение мира выполняется целым снимком при действии игрока, что ограничивает производительность. Для большего онлайна нужно перейти к транзакционным точечным SQL-операциям.
- Физический тест Windows + Android не проводился; серверные, сетевые и графические тесты автоматизированы.

## Rollback (только при подтверждённом инциденте)

1. Временно откатить `latest.json`, `server.json`, страницу и ссылки на v0.4.1 из контролируемого Git commit или релизного бэкапа.
2. Удалить `/etc/systemd/system/eldoria-ws-test.service.d/v050-persistence.conf`, затем `systemctl daemon-reload && systemctl restart eldoria-ws-test.service`. Старый unit работает из `/srv/bacus/apps/eldoria-test-server/client`. Старые ZIP/APK сохранены на сайте.
3. PostgreSQL volume и приватный API не удалять: пользовательские данные v0.5.0 должны оставаться доступными после восстановления. При необходимости применить только протестированную миграцию повторного выпуска.

**Важное ограничение:** snapshot-перезапись всего мира пока не масштабируется на большие онлайны; для реального MMO потребуется event/transaction-per-action.
