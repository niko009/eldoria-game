# Eldoria — TASK-057/058: боевые анимации героев и волков

**Начато:** 4 ноября 2026. **Этап:** 1 из [плана полировки](ELDORIA_POLISH_TO_SURVIVAL_ROADMAP.md). **Релиз:** не выполнялся; production v0.5.13, feature-база TASK-056.

## TASK-057 — настоящие движения героев

Из существующих лицензированных KayKit GLB (Knight, Rogue, Mage) теперь используются реальные skinned-анимации вместо универсальной анимации поднятия предмета:

| Действие | Импортированный clip | Продолжительность visual, с |
|---|---|---:|
| Выстрел из лука | `2H_Ranged_Shoot` | 0,52 |
| Выпад копьём | `2H_Melee_Attack_Stab` | 0,56 |
| Кулак | `Unarmed_Melee_Attack_Punch_A` | 0,56 |
| Блок щитом | `Block_Hit` | 0,46–0,52 |
| Рывок разбойника | `Dodge_Forward` | 0,38 |
| Заклинание лечения мага | `Spellcast_Shoot` | 0,68 |
| Получение урона | `Hit_A` (или блок щитом) | 0,37 |

Все action clips — одноразовые, с возвратом к Idle; скорость анимации масштабируется под ~650 мс серверного cooldown вместо ожидания полной исходной 1–1,6-секундной записи. Новые `hero_ability_visual` и `player_hurt_visual` RPC рассылаются **после** сервером принятого действия. Клиент не может выдать себе урон, лечение, рывок, XP или ресурсы при помощи анимации.

## TASK-058 — реакция волков

- У процедурной модели волка появилась нижняя челюсть; при **подтверждённой сервером атаке** волк раскрывает пасть, делает короткий выпад, затем возвращается в нейтральную позу.
- При снижении полученного по сети HP срабатывает краткая «вспышка» шерсти; повтор одинакового `snapshot` эффекта не создаёт.
- `wolf_attack_visual` направляет анимацию отдельному волку или конкретному волку стаи. При отклонённой атаке или действующем cooldown новых bite-событий нет.
- Эти эффекты не влияют на AI, физику, позиции, здоровье или сетевой авторитет сервера. Не добавляют постоянные частицы и меши в каждый кадр.

## Оставшиеся ограничения

- Это значительное улучшение **визуальных анимаций**, но не художественная замена самих моделей. У волка пока нет полноценного GLB-скелета, шерсти, анимаций смерти, у героев — профессиональных монтажных переходов.
- Корректность и скорость анимаций на физических Android ещё не измерены. Перед релизом выполнить плейтест и FPS/frametime-проверку на двух телефонах и Windows.
- Для production нужна полная совместная сборка сервера и клиентских Windows/Android версий, поскольку добавлены визуальные RPC.
