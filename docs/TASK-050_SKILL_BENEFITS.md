# TASK-050 — Реальные бонусы навыков и панель прогресса

**Ветка:** `feature/TASK-050-combat-skill-benefits`, основание `release/eldoria-v0.5.11`.
**Статус:** только разработка. **Релиз, production API и PostgreSQL не изменять.**

## Механика

Сервер рассчитывает бонус только по сохранённому `player_skills[player_id]`, а не по переданному клиентом уровню/урону. Сетевая схема, SQL и формат профиля не менялись.

| Уровень | Необходимый общий XP | Лук, урон | Копьё, урон | Щит, поглощение |
| ---: | ---: | ---: | ---: | ---: |
| 1 | 0 | 20 | 30 | 40% |
| 2 | 25 | 22 | 32 | 45% |
| 3 | 100 | 24 | 34 | 50% |
| 4 | 225 | 26 | 36 | 55% |
| 5 | 400 | 28 | 38 | 60% |

Отображаемый уровень = `1 + floor(sqrt(XP/25))`; XP сохраняется до миллиона, однако **боевой бонус перестаёт расти после уровня 5**. Входящий урон щитом округляется вверх и всегда минимум 1. Без экипированного и принадлежащего игроку щита снижение не действует.

- Лук применяет урон по выбранной сервером цели после проверки попадания/препятствий, расход стрел и cooldown остаются прежними.
- Копьё применяет усиление в серверном ближнем бою и по волкам, и по мирным существам.
- Щит снижает урон только при фактическом наличии и экипировке на сервере.
- XP за подтверждённые попадания/защиту начисляется как в TASK-049: новые правила не позволяют клиенту прислать произвольный XP или урон.
- Уникальная строка `skill` в сохранении остаётся неизменной — **миграция не требуется**.

## Интерфейс

- Новая кнопка с пиктограммой звезды в верхнем меню, отдельная вкладка **«Навыки»**.
- Для лука, копья и щита показаны текущий уровень, бонус, XP, прогресс до следующего уровня и подсказка об ограничении эффекта пятым уровнем.
- Полученный через `skill_snapshot` прогресс обновляет открытую вкладку без повторного открытия.
- Пять вкладок помещаются в Android landscape; прокрутка работает. Режим UI Preview содержит демонстрационный экран навыков.
- Компактная строка уровней HUD использует ту же функцию, что и сервер, без расхождений на порогах XP.

## Контрольные проверки

- `Godot --headless --path client --script res://tests/task050_skill_balance_e2e.gd`: границы XP, верхний предел бонусов, реальный урон волку, лишение щита и невозможность усилить неподдерживаемое оружие.
- `Godot --headless --path client --script res://tests/task050_skills_ui_e2e.gd`: Android-подобное окно, реальная кнопка открытия, полосы прогресса, текущие бонусы, обновление по snapshot.
- `bash tests/run_task050_skills_network_e2e.sh`: dedicated WebSocket и два реальных headless клиента: игрок с 400 XP лука наносит 28 урона, новичок — 20; XP+2 начисляется им отдельно; оба видят результат.
- `bash tests/run_dev_gameplay_e2e.sh`: полная регрессия Godot, ENet/WSS, крафт, стройка, мир, Android UI, сохранения и OpenGL.

**Проверки перед релизом:** реальные Android FPS и читаемость вкладки, баланс 2–3 игроков, длительная сессия. Для v0.5.11 в PostgreSQL нет записанных FPS-замеров; отсутствие измерений нельзя трактовать как нормальную производительность.
