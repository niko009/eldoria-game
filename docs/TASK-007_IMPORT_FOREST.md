# TASK-007 — Eldoria 0.3.0: полноценные 3D-модели леса

Дата: 2026-11-01. **Релиз 0.3.0**.

## Достоверное содержимое

- Godot 4.5.2 (единый проект Android ARM64 + Windows x64), прежняя сетевая логика ENet/WSS не менялась.
- Вместо примитивных крон/стволов импортированы **17 glTF-моделей** Quaternius Stylized Nature MegaKit STANDARD: 8 разновидностей деревьев, папоротник, кустарники, травы, цветы, грибы и валуны. Содержатся в `client/assets/nature`, импортируются Godot как сцены из оригинальных glTF и текстур.
- Процедурный ландшафт сохранён: тропа, озеро, рельеф, ориентир, добавлены дальние хребты. Семя генерации фиксировано. Поляна для игроков остаётся свободна, сетевой spawn не изменился.
- PC High: тени, полная растительность. Android Low: тени отключены, часть декоративной травы/дальних деревьев скрыта. Общий мир и координаты не изменяются.
- `client/tests/forest_screenshot.gd` создаёт **реальный** рендер Godot OpenGL Compatibility, сохранённый как `forest-preview.png` на сайте. Это не концепт-арт.
- Ссылка на API обновлений: `https://bacus.dev/projects/eldoria/latest.json`; манифест для 0.3.0 генерируется из реальных ZIP/APK, не из произвольных значений. Обновляющийся клиент 0.2.1 должен увидеть новую версию.

## Известные ограничения

Это яркий стилизованный (не фотореалистичный) лес. Мир пока не имеет физической коллизии рельефа, разрушаемости, постоянного состояния, аккаунтов и серверного античита. Текущий публичный сервер тестовый и допускает анонимных игроков. Большие 3D-модели увеличивают размер APK с ~27.7 до ~48.2 МБ. Дальнейшая оптимизация мобильной графики требует профилирования на реальном телефоне.
