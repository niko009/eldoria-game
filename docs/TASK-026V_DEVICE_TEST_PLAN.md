# TASK-026V: замеры на двух Android

## Подготовка

Использовать одну и ту же сборку клиента на двух физических телефонах. Записать модель, версию Android, разрешение экрана, частоту обновления и состояние энергосбережения **в локальном протоколе тестирования**, не в сетевой телеметрии. Перед серией дать устройству остыть, зарядить его и отключить фоновые задачи. Сеть нужна только для входа в игру; производительность измерять локальным overlay.

Открыть настройки → «Диагностика FPS (F9)» (на Windows также F9). Режим выключен по умолчанию и ничего не отправляет. Установить качество Low или High через меню. Показатели FPS и p95 считаются по последним 300 кадрам; дождаться заполнения окна перед записью.

## Маршрут

Для каждого телефона пройти все шесть сочетаний: три точки × Low/High. Точки: **camp** — стартовая поляна и тропа; **forest** — густая роща за стартовой поляной; **lake** — берег водоёма с горами в кадре. Удерживать сходный ракурс, стоять на месте, не открывать инвентарь и не менять масштаб. После 60 секунд прогрева записывать показания overlay каждую минуту **3–5 минут**. Затем пройти короткий маршрут через сцену и отдельно отметить заметные фризы и нагрев.

| Телефон | Сцена | Quality | Медиана avg FPS | Медиана 5%-low FPS | Медиана p95, мс | Фризы / нагрев |
|---|---|---|---:|---:|---:|---|
| A/B | camp/forest/lake | Low/High | | | | |

Повторить тот же маршрут для исходной версии, если требуется сравнение до/после. Сравнивать только на одном телефоне, с тем же разрешением, состоянием питания и игровым ракурсом. High на Android может оказаться медленным; целевой FPS без физических измерений не заявляется. Облачные агрегаты TASK-018 не привязаны к устройству или сцене и не заменяют этот протокол.
