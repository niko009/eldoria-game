## Условия старта

- В журнале выбора записаны конкретный вид/model_id, версия, источник, лицензия, визуал/анимации, диапазон опасности и подтверждение пользователя.
- Базовый PvE уже обслуживает существующих мобов; не требовать утверждённых новых мобов для реализации квестового движка TASK-088.

## Реализация на каждого моба

1. Asset import/rig/clip mapping и лицензия в репозитории; анимации Idle/Move/Attack/Hit/Death либо явно согласованная замена, без silent placeholder.
2. Отличимые **уровень сложности, AI, атака, поведение** (соло/группа, day/night, агрессивный/нейтральный/ответный) — не просто разные HP/окраска.
3. Серверные spawn/aggro/target/attack/death/despawn/loot/XP, корректная видимая HP шкала TASK-089; защитить от лута/XP за отклонённые или повторённые события.
4. Синхронизация 2 клиентов WSS, обработка reconnect и persistence согласно текущему контракту; профилирование количества мобов/анимаций для Android Low, границы количества одновременно активных существ.
5. Для каждого вида отдельные видео/кадры анимаций в запущенном Godot и игровой тест. Сначала один mob vertical slice, затем следующие после проверки; release только отдельным решением.

## Важное ограничение

**Минимум четыре новых вида**, но это будущая цель, а не статус production v0.5.26. Концепт, готовая модель и интегрированный моб — три разных состояния. Нельзя выдавать найденные файлы за внедрённую механику.
