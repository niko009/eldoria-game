Аудит начинается с того, что уже есть: не следует считать наличие 85 ассетов доказательством готовой стилистики. Два направления для **будущих изолированных preview**, без автоматической смены дизайна: (1) **compact tactical** — теснее верхняя статистика, раздельное оружие/щит/количество расходников, приоритет атаки и revive; (2) **minimal explorer** — узкие постоянные показатели, ресурсы по запросу и контекстные подсказки. Референсы должны быть сопоставлены на одинаковых кадрах Godot, затем **B-02/B-03** approval.

## Границы и release gate
- Не смешивать статус `TESTED` с `DONE`. Все пять задач могут быть полностью `DONE` только по реальным acceptance criteria.
- Новый код A-12 в feature-ветке не публикуется как production без нового тестового Android APK и пользовательского playtest.
- Четыре автономных пункта переведены из `IN_PROGRESS` в `TESTED` с явным ограничением; A-04 всё ещё `IN_PROGRESS`.
- Релизная ветка production остаётся `release/eldoria-v0.5.28`. Не запускать migration/dump и не изменять live API для этих пяти UI/кооперативных задач.
