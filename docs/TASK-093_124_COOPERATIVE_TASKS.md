## P0 — первое завершённое приключение на имеющихся ассетах

### TASK-093 — Первый результат за 5–10 минут
**A / P0.** Короткое необязательное обучение на существующих действиях: собери → изготовь → используй → получи XP/ресурс, без большого текста. **AC:** новый игрок за 10 минут понимает, что делать дальше; после reconnect прогресс сохраняется, reward выдаётся один раз, соло работает. Использовать движок TASK-088, не создавать второй.

### TASK-094 — Настоящая группа и общий индикатор задания
**A / P0.** Добровольное приглашение напарника без логина, серверный идентификатор временной группы, общая цель/счётчик/ориентир, **личные** инвентари и награды. **AC:** два клиента видят синхронный прогресс; случайный сосед по миру не получает командный лут; join/leave/reconnect и solo корректны; верх HUD не мешает управлению. Запретить фальшивые запросы от посторонних.

### TASK-095 — Спасти раненого напарника
**A / P0.** При смертельном ударе в кооперативе дать короткую возможность поднять союзника удержанием действия с безопасного расстояния; соло и при пропущенном таймере — обычное возрождение. **AC:** видно «ранен / помогите», оживление нельзя проводить сквозь стену, при атаке или после таймера; нет бессмертия, дюпа лута/XP, рассинхронизации 2 клиентов. Длительность и стартовое HP настраиваются после плейтеста.

### TASK-096 — Командные преимущества классов
**A / P0.** Не переписывать уже существующие Knight taunt и Mage heal. Добавить ясную синергию рыцарь отвлекает/блокирует → маг замедляет/лечит; разбойник метит цель/обходит и использует рывок. **AC:** у каждой из пар Knight/Mage/Rogue есть минимум один полезный командный приём; без обязательного состава команды, cooldown/действие видны; сервер проверяет цель, ману, урон и агро; спам не даёт бонуса.

### TASK-097 — Кооперативное взаимодействие в руинах
**A / P0.** Две кнопки/рычага на существующей POI: вдвоём одновременно быстро, одиночка — последовательный способ с более долгим действием/ресурсом. Первоначально использовать только простые тестовые меши. **AC:** 1/2 игрока могут завершить, сервер проверяет расстояние/время и один payout; после падения клиента нет soft-lock; 2 клиента видят один результат.

### TASK-098 — Первая законченная глава «Следы в лесу»
**A / P0.** Квест 25–40 минут на **существующих** руинах, руническом круге, заброшенном лагере, волках: старт → разведка → совместное действие → схватка → вернуть находку/награда. Не требовать TASK-092 или художественного утверждения. **AC:** 3–5 этапов, заметная следующая цель, работающие соло/дуо, сохранение после рестарта, уникальная награда/открытие, один законченный игровой цикл. Лор и названия — временные.

### TASK-099 — Тактический босс из существующего альфа-волка
**A / P0.** Добавить к существующему alpha wolf 2 читаемых боевых паттерна с окнами ответа (укус, рывок или рёв), смену фазы и безопасный повтор после поражения. **AC:** нет мгновенно неизбежной смерти, блок/лечение/рывок влияют на исход, сохраняется server authoritative hit, видны предупреждения, тест соло и двух игроков. Продолжает старую TASK-082.

### TASK-100 — Командная победа, персональная награда
**A / P0.** Наградной экран: что выпало, за что начислен XP/материалы, что открыто на будущее; видно помощь каждого без навязчивого leaderboard. **AC:** награда начислена только сервером, ровно один раз после retry/reconnect/PG restart, чужой участник её не крадёт, UI не показывает фиктивную выдачу. Расширяет старые TASK-081 и TASK-088.

### TASK-102 — Баланс для одного и двух игроков
**A / P0.** Регулировать число волн, длительность предупреждения и агро по **активным** участникам, а не механически удваивать HP. Поздний join не позволяет получить награду за чужую победу. **AC:** соло/дуо проходят один сюжет без unfair wipe; зафиксированы TTK/число смертей и возможность использовать повязку; нет эксплойта reconnect.

### TASK-104 — Тест реального 60-минутного приключения
**A / P0.** Автоматический WSS E2E + ручной Android/Windows сценарий из [протокола](ELDORIA_COOP_PLAYTEST_PROTOCOL.md). **AC:** вход 2 игроков → помощь → мини-экспедиция → босс → добыча → улучшение; отдельные записи об ошибках и скучных местах; оценку интереса ребёнком нельзя заменить тестом кода.

## P1 — причины возвращаться в игру

### TASK-101 — Полезные улучшения лагеря
**A / P1.** Минимум 2 улучшения с реальным эффектом: защита/лечение и хранилище с явными правами. **AC:** оба игрока видят функциональность, никто посторонний не берёт вещи, весь прогресс сохраняется; новые красивые модели отдельно в B-02.

### TASK-103 — Осмысленная цепочка крафта
**A / P1.** Добыча вдвоём → изготовить полезный предмет текущими ресурсами → применить в следующем бою. **AC:** работает расходование/сохранение/отказ, понятные подсказки и быстрый доступ. Использовать старые TASK-070/071/075, не плодить второй интерфейс/движок.

### TASK-105 — Повторяемые экспедиции на 10–20 минут
**A / P1.** Три варианта: охота, разведка, оборона; меняются цели и награды, но не требуют новой карты или рандомного бесконечного фарма. **AC:** сценарии ощущаются разными, replay idempotent, solo/duo, нет принуждения заходить ежедневно.

### TASK-106 — Небольшие тайники и сокровища
**A / P1.** В существующих точках интереса положить исследовательские находки с подсказкой/разгадкой. **AC:** оба видят тайник, но reward персональный и одноразовый, нет невидимых из-за Low предметов; solo доступно.

### TASK-107 — Полезная роль разбойника
**A / P1.** Ограниченная ловушка/предупреждение и командная метка врага; не давать бесконечно держать босса. **AC:** cooldown, дальность, стоимость предмета и здоровье/агро контролирует сервер; тактический эффект заметен обоим.

### TASK-108 — Разные ночные нападения
**A / P1.** Два типа обороны на текущих волках: защитить костёр или сопровождать раненного/восстановить лагерь после нападения. **AC:** разные цели, ясный сигнал победы, награда за успех, нет неконтролируемого спауна.

### TASK-109 — Сопроводить потерявшегося NPC
**A / P1.** Короткий путь из леса в лагерь, NPC следует за группой, останавливается и реагирует на опасность. **AC:** восстановление после застревания/отключения, один payout, solo можно; внешняя одобренная 3D-модель не нужна для dev.

### TASK-110 — Не терять напарника
**A / P1.** Ограниченные во времени отметки «сюда / опасность / помоги» и стрелка направления для своей группы, без открытого текстового чата. **AC:** rate-limit, скрыто от посторонних, не перекрывает управление и цели.

### TASK-111 — Качественные улучшения оружия
**A / P1.** 2 доступных уровня существующего меча/лука/щита/посоха со сравнением характеристик и ощутимым тактическим эффектом. **AC:** игрок видит пользу, материалы расходуются один раз, не ломается сохранение/баланс; арт и новые 3D-модели только B.

### TASK-112 — Разный рост классов
**A / P1.** По 1–2 альтернативных улучшения класса: рыцарь — защита союзника, маг — контроль/лечение, разбойник — разведка/метка. **AC:** хотя бы одно улучшение можно получить за 60 минут, магический XP не смешивается с melee, смена класса не стирает прогресс.

### TASK-113 — Маленькие достижения без FOMO
**A / P1.** «Исследовал руины», «спас союзника», «победил альфу» и следующий понятный шаг. **AC:** заслуженное достижение выдаётся однажды, отображает реально сохранённый прогресс, нет обязательных ежедневных наград.

### TASK-114 — Сигнал помощи и безопасный сбор группы
**A / P1.** Видеть статус напарника рядом/далеко/ранен, предложить вернуться к общему лагерю, без бесплатной боевой телепортации. **AC:** не создаёт эксплойтов при смерти/отключении, чужие профили не раскрываются, уведомления не спамят.

- Все игровые события и выдача XP/предметов авторитетны на сервере; обязательна идемпотентность после retry/reconnect.
- Перед началом задачи сверить код: некоторые старые TASK-070–083 частично существуют в релизе, избегать повторной реализации.
