# Eldoria — единый backlog интересного кооператива (после v0.5.26)

**Актуализировано:** 2026-11-06. **Статус:** проектный план, не реализованный функционал. Базовый Git: `release/eldoria-v0.5.26`; этот документ основан на существующей [двухочередной модели](ELDORIA_DEVELOPMENT_QUEUES.md). Не запускать релиз/миграцию production без отдельной команды.

## Проблема и решение

Сейчас у нас есть реальное перемещение, добыча, craft, 3 класса, магические атаки/лечение, щит и taunt, волки и альфа-волк, ночная оборона, лут и PostgreSQL. Но **нет связанного короткого приключения, общего понятного задания, спасения напарника и ощутимого выбора дальнейшей цели**. Игрок чаще делает механически одинаковые действия, чем принимает интересные решения с другом.

**Цель ближайшего игрового среза:** вдвоём (два Android или Android+Windows) без инструктора зайти, за **5 минут** понять куда идти, за **10 минут** сделать первое полезное командное действие, за **30–45 минут** пройти мини-приключение с развязкой и получить награду; в пределах **60 минут** улучшить лагерь/снаряжение и увидеть следующую цель. Играть одному можно: кооператив помогает, **но ни один базовый сюжетный шаг не блокируется навсегда без второго игрока**.

## Не создавать повторно

Реально существующие элементы, которые нужно расширять, а не переписывать: `_shield_taunt_on_server`, магические атаки и лечение, `_wolf_bite_ready` (предупреждение укуса), `_reward_raid_survivors`, крафт и предметы `bandage/mana_potion/wooden_staff`, сохранение экипировки, существующие три ориентира мира. Реальная степень завершённости старых TASK-070–083 требует сверки с текущим кодом и мобильными тестами: [реестр сверки](ELDORIA_LEGACY_BACKLOG_RECONCILIATION.md).

Незакрытая база: [TASK-087](TASK-087_GAMEPLAY_WORLD_UI_POLISH.md) (стрелы, управление, hotbar, деревья), [TASK-088](TASK-088_QUESTS_AND_MAGIC_PROGRESSION.md) (квесты и магический XP), [TASK-089](TASK-089_MOB_HEALTH_BARS.md) (HP), [TASK-090](TASK-090_ASSET_AND_UI_AUDIT.md) (арт/UI), [TASK-091](TASK-091_MOB_SELECTION.md) / [TASK-092](TASK-092_MOB_IMPLEMENTATION.md) (4 новых моба после показа/согласования).

## Объективная проверка интереса

Главное — не число задач. Каждый релиз игры должен доказывать: игрок может объяснить текущую цель без подсказки; второй игрок влияет на исход; после события есть читаемая награда; за 30 минут происходит хотя бы одно событие, которое игрок хочет повторить. [Сценарии и наблюдаемые критерии](ELDORIA_COOP_PLAYTEST_PROTOCOL.md). Фактическая оценка интереса ребёнком — только реальный совместный плейтест, не автоматизированный PASS.
