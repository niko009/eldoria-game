# TASK-008 — Eldoria v0.3.1: физические препятствия и FPS

## Исправления

- В предыдущем прототипе координаты игрока менялись напрямую, не существовало проверки столкновений. Теперь `forest_world.gd` строит детерминированные препятствия по стволам 3D-деревьев и валунам; `move_actor` запрещает пересечение и обеспечивает скольжение вдоль объектов. Положение по Y вычисляется из исходного `height_at()`.
- Сервер WSS/ENet использует **те же** координаты препятствий и `valid_remote_step`, отвергает проход сквозь деревья/камни, некорректную высоту и резкие прыжки и отправляет коррекцию собственному игроку. Это пока прототип проверки; не гарантирует полной защиты от читов.
- Проверка движения вынесена в `_physics_process` с фиксированным timestep; передача позиции ограничена 20 Гц при движении вместо отправки каждый кадр. На экране отображается текущий FPS.
- Реальные glTF объекты, которые раньше составляли сотни отдельных MeshInstance3D, группируются по типу в `MultiMeshInstance3D`; измерено 24 render-группы для леса (17 активных при Low), 103 деревьев и 164 фиксированных препятствия в текущем сидовом мире.
- Android по умолчанию Low, PC High; переключатель качества теперь доступен на обеих платформах. Low скрывает часть травы/цветов, **но деревья с коллизиями остаются видимыми**.

## Что не реализовано

- Нет полной коллизии с листвой, травой, всеми моделями и другими игроками; твёрдые препятствия — стволы/валуны, движение по холмам — через высоту ландшафта.
- Для точных форм камней используются приближённые круги, а не физические полигоны.
- Прирост FPS на физическом Android неизвестен без реальных замеров. `MultiMesh` уменьшает количество отдельных render-объектов, но не гарантирует конкретный FPS.
- Встроенный прототип остаётся анонимным и не является production-MMORPG.

## Автотесты

- `client/tests/collision_perf_e2e.gd`: проверка запрета прохождения через ствол, серверной валидации, скольжения, обхода, следования рельефу, сохранения физических ограничений при Low и группировки MultiMesh.
- `tests/run_network_e2e.sh`, `tests/run_dedicated_e2e.sh`, `tests/run_websocket_e2e.sh`, `tests/run_discovery_e2e.sh`: движение 2 игроков, Wave, disconnect/rejoin.
- Сборки Windows x64 ZIP и Android ARM64 debug APK публикуются с версиями 0.3.1 / Android versionCode 8. Одинаковая подпись APK с 0.3.0 обязательна.
- Публичный WSS endpoint `wss://bacus.dev/eldoria/ws`, HTTPS manifest `latest.json`. Проверять реальное подключение после обновления сервера и файлов.

## Риски и дальнейшие действия

Проверить FPS и физическое движение на **реальном Android** и **реальном Windows**. При необходимости добавить удаление невидимого декора за пределами камеры, GPU-level profiling, chunk streaming, серверные PhysicsBodies. Замеры headless/Linux не должны подаваться как аппаратные Android тесты.
