# TASK-010 — Eldoria v0.4.1: направление персонажей

## Причина
В v0.4.0 KayKit GLB ориентированы лицом по локальной оси +Z, но `animated_actor.gd` рассчитывал направление поворота как для моделей, смотрящих вдоль Godot -Z. Это давало разворот на 180° и ходьбу спиной вперёд.

## Исправление
Только визуальный угол модели: `atan2(flat.x, flat.z)` вместо `atan2(-flat.x,-flat.z)`. Не меняли физическое перемещение, препятствия, скорость, сетевой протокол и состояние сервера. На ПК Shift — sprint, на Android кнопка Sprint как прежде.

## Проверки
- `tests/run_character_e2e.sh` проверяет yaw и вектор лицевой оси +Z для каждого из 3 персонажей во всех четырёх направлениях; Idle/Walk/Run/Cheer PASS.
- `tests/run_network_e2e.sh`, `tests/run_dedicated_e2e.sh`, `tests/run_websocket_e2e.sh`: PASS.
- Windows x64 ZIP v0.4.1, Android signed APK v0.4.1 (versionCode 10) экспортированы; Android signing cert совпадает с v0.4.0.
- Публичный сайт: версия в latest.json и server.json обновляется после размещения ZIP/APK; используем предыдущий WSS-сервер, так как код игрового протокола не менялся.
- **Нет** проверки физического Android/Windows устройства, только воспроизводимый headless E2E, экспорт и хэш-контроль скачивания.
