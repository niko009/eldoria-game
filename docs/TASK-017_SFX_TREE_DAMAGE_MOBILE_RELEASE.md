# TASK-017 — Звуки, повреждения дерева и мобильное строительство: Eldoria v0.5.1

**Release:** 2 ноября 2026. Пользователь разрешил разработку и выпуск. Версия **v0.5.1** опубликована на `https://bacus.dev/projects/eldoria/`.

## Новое в релизе

### Звуки
- `tools/generate_sfx.js` синтезирует четыре **оригинальных**, детерминированных WAV 22,050 Гц mono/16-bit: `wood_chop.wav`, `stone_hit.wav`, `herb_rustle.wav`, `build_place.wav`. Никаких сторонних музыкальных библиотек или лицензированных образцов.
- Успешные серверные события сбора и постройки запускают позиционный `AudioStreamPlayer3D`; до **6 одновременных** коротких звуков на клиент.
- `Sound: ON / OFF` переключает звук и сохраняет состояние в локальном `user://eldoria-sound.cfg`; muted звуки не проигрываются, активные останавливаются.
- Headless-сервер не создаёт аудио-узлы. Звук не хранится в PostgreSQL.

### Повреждения деревьев
- После первого/второго/третьего успешного сбора дерева возникают 1/2/3 набора тёмных 3D-следов ударов на коре. Они реализованы небольшим `MultiMeshInstance3D` только у повреждённых деревьев.
- После четвёртого сбора дерево падает (визуальный эффект TASK-016), затем исчезает; коллизия и метки повреждения удаляются.
- При загрузке сохранённого состояния или позднем подключении степень повреждения восстанавливается **из оставшегося количества древесины**; схема PostgreSQL не меняется.

### Android — удобное строительство
- Кнопка **Build mode** открывает компактное меню с выбором **Campfire/Tent**, предпросмотром позиции, крупными кнопками **PLACE** и **CANCEL**.
- Предпросмотр зелёный/красный, зависит от ресурсов и рельефа; PLACE передаёт подтверждение в существующий авторитетный Godot-сервер.
- После успешной постройки режим закрывается. На малых ландшафтных экранах панель адаптирует вертикальную позицию и не закрывает левый джойстик.
- Протестировано через реальный Godot/OpenGL UI при разрешении **720×360**. Физический Android не использовался.
- Windows управление сохранено: WASD, Shift, Space, F, B, V; меню постройки по клавише V/Preview.

## Бэкапы и откат

- До переключения сохранены v0.5.0 game files, страницы, manifest, Windows ZIP/APK и systemd drop-in: `/srv/bacus/backups/eldoria-pre-051-20261102/`.
- `world-pre051.dump` — проверенный `pg_dump -Fc` PostgreSQL, `pg_restore -l` PASS.
- Откат: вернуть systemd override `v050-persistence.conf` и перезапустить `eldoria-ws-test.service`; вернуть HTML/manifest/server.json v0.5.0 и старые ссылки из бэкапа. **Не удалять PostgreSQL volume** и не восстанавливать дамп поверх новой базы без оценки данных, появившихся после v0.5.1.
- Воспроизведение проигранного локального эффекта после переподключения не предусмотрено: звуки/анимации не сохраняются, сохраняются только изменение древесины, коллизии и постройки.

## Ограничения

Не проводились физические испытания Android и Windows, не измерен FPS мобильного GPU, не проверена фактическая громкость на динамиках. UI проверен симулированными touch-событиями и OpenGL/Xvfb на Linux. Текущее синхронное сохранение целого мира при сборе/строительстве ограничивает будущую масштабируемость.
