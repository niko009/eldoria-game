## Реализация

- Каменный топор: **2 дерева + 2 камня**, можно изготовить только в пределах **4 м** от установленного костра.
- Крафт и списание проверяет **только выделенный Godot-сервер**; клиент отправляет `request_craft_axe` без доверенных материалов/позиции. Повторное изготовление топора запрещено.
- Личный серверный инвентарь `axe: 0 или 1`; сохраняется в JSON тестовом снимке и PostgreSQL. Старые профили без `axe` подхватываются как `axe=0`.
- Пока топор есть в инвентаре, серверная добыча дерева приносит **до 2 дерева за удар**, строго ограничиваясь остатком на дереве (не даёт дубликаты). Отдельное ручное экипирование пока не требуется.
- Расходы крафта и добычи откатываются при ошибке сохранения мира. Проверен восстановительный сценарий после временного отказа хранилища.
- Живой UI v0.5.3: вкладка «Крафт» теперь показывает рецепт, материалы, необходимость близкого костра, блокирует кнопку вне костра, при отсутствии материалов и после получения одного топора. Сообщения о результате приходят от сервера; обновляется HUD, инвентарь и слот топора.
- Legacy Windows-тесты: клавиша **C**; старая Android-панель содержит кнопку, но реальный пользовательский интерфейс — новая вкладка «Крафт».
- Подготовлена миграция `server/Eldoria.Persistence/sql/003_stone_axe.sql`. **В production не выполнялась.** Следующий релиз v0.5.4 должен обновлять private API + миграцию + выделенный Godot host + клиент + HTTPS-конфигурацию версии согласованно.

## Известные ограничения

- Не выполнен визуальный и тактильный тест на реальном Android с крафтом; релиз ещё не выпускался.
- Топор даёт бонус владения, не требует экипирования; отдельная механика экипировки возможна позже.
- Только один рецепт и один топор. Долговечность, анимация инструментов, новые рецепты и расширенный станок — будущие задачи.
- Для следующего выпуска нужны новая production-миграция и backup текущей PostgreSQL-схемы/прогресса, production smoke для .NET, Godot и раздачи APK/ZIP, а также явное разрешение пользователя. Временная тестовая PostgreSQL `eldoria-task022-pg` удалена после PASS; `eldoria-task013-pg` и production не затронуты.
